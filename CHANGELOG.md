## [Unreleased]

### Added
- M0: монорепозиторий, миграция схемы из Приложения A (goose), сид каталога из `data/*.csv`,
  docker-compose, Makefile, CI (lint, тесты с `-race`, govulncheck, миграции up/down/up, Playwright).
- M1: JWT-аутентификация и роли, получатели с профилем value/source/confidence, поводы,
  импорт каталога CSV с построчным отчётом, наличие и цены, audit log.
- M2: Rules Engine (аллергены, питомцы, астма и запахи, неизвестный состав, бюджет, замены,
  уточняющий вопрос, приватный GiverView) с property-тестами по справочнику растений.
- M7 (частично): справочник растений сверен с ASPCA, ссылки на источник у каждой строки.
- M8 (частично): метрики Prometheus, rate limiting, прод-конфигурация с Caddy и TLS, бэкап и восстановление, runbook.
- M6: офлайн-оценка (`make eval`), черновой экспертный набор, исследовательский режим с согласием и экспортом,
  экспертная разметка, dashboard оценки, удаление аккаунта.
- M5: валидация замен (409 + журнал), отзывы, интерфейс для дарителя, флориста и менеджера,
  сквозной e2e-сценарий.
- M4: AI-ассистент по бюджету (Claude + детерминированный fallback), исключение позиции из набора,
  фильтры «Рядом», «Дешевле», «Со скидкой».
- M3: Top-5 букетов с объяснениями и confidence, уточняющий вопрос, нумерологический режим, история рекомендаций.
