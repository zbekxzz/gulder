# 0007. AI-ассистент: structured outputs, модель и fallback

- Статус: принято (M4)

## Контекст
§9 требует строго структурированный ответ LLM с ID позиций каталога, повторную проверку
каждого набора кодом и работу без сети (fallback). §3: модель из `LLM_MODEL`, ключ `ANTHROPIC_API_KEY`.

## Решение
- **Структурированный ответ — structured outputs** (`output_config.format` с JSON-схемой,
  `additionalProperties: false`), а не принудительный `tool_choice`: на текущих моделях Claude
  `tool_choice: any/tool` возвращает 400. Ответ всё равно разбирается и валидируется кодом.
- **Модель по умолчанию — `claude-opus-5-5`**, переопределяется `LLM_MODEL`. Effort `medium`.
- **Отказ модели** (`stop_reason: refusal`): включён серверный `fallbacks: "default"`
  (beta `server-side-fallback-2026-07-01`) — запрос в том же вызове обслуживает резервная модель.
  Если ответа всё равно нет, срабатывает наш детерминированный fallback.
- **Таймауты**: 20 с на запрос (`LLM_TIMEOUT`), до 2 повторов с экспоненциальной задержкой
  (делает SDK для 408/429/5xx и сетевых ошибок). Ошибка LLM → fallback, а не 5xx для пользователя.
- **В промпт** попадают только допущенные позиции (id, название, цена, категория, краткие признаки,
  предупреждения после GiverView), повод и бюджет. Профиль получателя не передаётся. Промпт не логируется.
- **Валидация кодом**: ID только из списка кандидатов (FR-G02), `CheckGiftSet ≠ BLOCK`, сумма ≤ бюджета,
  наборы различаются букетом или ≥ 2 подарками. Цена, остаток, предупреждения считаются кодом.
  Если валидных наборов < 2 — один повтор с перечнем ошибок, затем fallback добирает недостающие.
- **Исключение позиции (FR-G04)** подбирает замену детерминированно (тот же жадный алгоритм, что и fallback):
  дешевле, быстрее и воспроизводимо; LLM здесь не нужен.
- `gift_sets.excluded_item_ids` хранит исключённые подарки, а `excluded_bouquet_ids` (миграция 00004) — букеты:
  id из разных таблиц могут совпадать.

## Альтернативы
- Tool use с `tool_choice: auto` и инструкцией вызвать инструмент — менее надёжно, чем схема ответа.
- Передавать LLM весь каталог — дороже и нарушает требование «только допущенные позиции».

## Следствия
Без ключа (локально, в тестах и CI) ассистент полностью работоспособен на fallback; ответ помечен
`generator: "fallback" | "llm"`. Тесты используют моки, нарочно нарушающие бюджет и предлагающие
запрещённые/чужие позиции, и фейковый HTTP-сервер API для проверки формы запроса.
