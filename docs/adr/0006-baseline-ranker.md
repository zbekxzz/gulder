# 0006. Baseline-ranker: трактовки §8.1

- Статус: принято (M3)

## Контекст
§8.1 задаёт факторы и веса, но оставляет открытыми: что считать «неизвестными полями» для
нейтральности, базовую уверенность, таблицу повода и детали объяснений.

## Решение
- Веса — `internal/ranking/ranking.yaml` (встроен в бинарник, можно подменить `RANKING_CONFIG`).
  Версия весов = `model_version` (`baseline-0.1`). Конфиг проверяется: сумма базовых весов = 1, нумерология ≤ 0.15.
- **Неизвестные поля для FR-R02** — только поля безопасности (allergies, pets, asthma, scent_sensitivity):
  `w_neutral = 0.05 + 0.05 × unknown_count`, затем перенормировка. Максимум — 0.25 до нормировки.
- **Нейтральность букета** = среднее из (1 − запах/3), (1 − пыльца/3), «нет растений, токсичных для кошек/собак».
- **Базовая уверенность** = 0.2 + 0.8 × взвешенная доля известных полей (allergies .25, pets .20, asthma .15,
  scent .15, liked_flowers .10, liked_colors .10, style .05). Пол 0.2: даже при пустом профиле рекомендация
  опирается на повод и бюджет. Итог = база × `ConfidenceMultiplier()` из Rules Engine, затем Platt (M6).
- **occasion_fit** — таблица «повод → стили, цвета, форматы» + цвета эмоции + формальность (≥4 → классика/минимализм,
  ≤2 → не классика), среднее компонентов. Неизвестный повод → 0.5.
- **flower_match/color_match**: любимые неизвестны или пусты → 0.5; иначе доля стеблей любимых; минус 0.5 × доля нелюбимых.
- **budget_fit**: цена > max → исключается из Top-5 (это не решение безопасности и в `excluded_count` не входит).
- **season_avail**: не в наличии → 0; иначе доля стеблей в сезоне на дату повода (нет даты — «сейчас»).
- **Приватность объяснений**: если предпочтение указал получатель, причина обобщённая
  («Совпадает с предпочтениями получателя»), а конфликт виден только как `RECIPIENT_RESTRICTION` в warnings.
- Порядок при равном score: дешевле, затем меньший id; сумма факторов — в фиксированном порядке.

## Следствия
Веса и таблицу повода нужно откалибровать на проверенной экспертной разметке (M6–M7). Любая правка
весов — новый `model_version`.
