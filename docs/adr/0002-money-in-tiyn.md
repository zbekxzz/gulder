# 0002. Деньги — целые тиыны (`domain.Money`)

- Статус: принято (M0)

## Контекст
§7.2 и §18.3: деньги не во float. В БД — `numeric(12,2)` в тенге.

## Решение
`type Money int64` — сумма в тиынах. Разбор строки без округления (больше двух знаков — ошибка).
В JSON — число в тенге с минимальной записью (`15000`, `129.5`), на вход — число или строка.
В БД — через `sql.Scanner`/`driver.Valuer` десятичной строкой (pgx отдаёт numeric строкой).

## Альтернативы
- `shopspring/decimal`: лишняя зависимость; нам хватает сложения и сравнения.
- float64: запрещено заданием.

## Следствия
- Сумма набора и проверка бюджета (`OVER_BUDGET`, AC-4) точны.
- Фронтенд получает числа в тенге; на клиенте только отображение, без арифметики над ценами.
