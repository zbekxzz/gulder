# Сквозной сценарий (walkthrough)

Этот сценарий — одновременно ручная проверка и e2e-тест: [`frontend/e2e/walkthrough.spec.ts`](../frontend/e2e/walkthrough.spec.ts).
Запуск: `make test-e2e` (поднимает API и Vite сам; нужен `E2E_DATABASE_URL` или `docker compose`-стек).
Скриншоты шагов: `E2E_SCREENSHOTS=/путь/к/папке make test-e2e`.

Данные: `make seed` (dev-пользователи с паролем `gulder-dev-password`).

## Шаги

1. **Вход дарителя** `giver@gulder.local`.
2. **Первый получатель** «Сестра»: аллергий нет (знаю), животных нет (знаю), любимые цветы — лилии.
   Повод «День рождения», бюджет до 40 000 ₸ → «Подобрать букеты». В Top-5 есть лилии.
3. **Второй получатель** «Кошатница»: тот же вкус (лилии), но дома кошка; аллергии, астма и запахи — «не знаю».
   Тот же бюджет → Top-5 **отличается** (AC-1): лилии и другие токсичные для кошек растения исключены
   Rules Engine ещё до ранжирования (FR-R01), на странице видно «Исключено по ограничениям: N».
4. **Уточняющий вопрос** (FR-R04): сверху «Есть ли у получателя аллергия…» с быстрыми ответами.
   Ответ сразу записывается в профиль и пересчитывает подборку (новый запуск).
5. **Наборы ассистента** (FR-G01–G03): «Собрать наборы» → 3 набора «букет + подарки» с итогом и остатком
   бюджета; без `ANTHROPIC_API_KEY` их собирает детерминированный fallback (пометка «авто»).
6. **Исключение позиции** (FR-G04): «убрать» у подарка → набор пересобран с заменой в пределах остатка.
7. **«Рядом»** (FR-L01, FR-L02): браузер спрашивает разрешение на геолокацию (только по клику); карточки
   сортируются по расстоянию, на карте — магазины и часы работы. При отказе можно выбрать точку на карте.
   Координаты нигде не сохраняются.
8. **Флорист** `florist@gulder.local` → «Каталог» → «Замены»: букет AB-001 (25 красных роз), повод
   кошатницы (номер показан на странице подборки), «Роза Red Naomi» → «Лилия восточная Siberia».
   Мгновенная проверка: **«Замена запрещена»**, кнопка «Применить замену» неактивна (AC-3, UI).
9. Прямой запрос к API с той же заменой получает **409** — API проверяет независимо от UI (AC-3, API).

## Что ещё посмотреть вручную

- Профиль: при «Не знаю» поле значения не вводится; «Знаю» + пустой список = явное «нет» (AC-2).
- Карточка: причины, конфликты, «не хватает сведений», предупреждения, нумерология с пометкой
  «развлекательная функция», дисклеймер «известных противопоказаний не найдено».
- Флорист: импорт CSV с построчным отчётом, неподтверждённые растения, цены и скидки.
- Менеджер `manager@gulder.local`: правила и справочник, нумерология (новая версия при сохранении),
  качество данных, аналитика.
